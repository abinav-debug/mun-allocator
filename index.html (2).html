JSONBin — shared state storage
JSONBin stores your locked allocations so everyone on your team sees the same data when they open the link.

Setup (free, 2 min):
1. Go to jsonbin.io → create a free account
2. Go to API Keys → create a key → paste it below
3. Click "Create bin" once — the Bin ID is saved automatically
Experience score ranges 🔐 Admin only
Delegates enter a numeric experience score. Set the cutoffs below to map scores to levels. Scores are always rounded up before mapping — so 3.4 becomes 4.
Admin password
